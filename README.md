# Liquid type experiment

An independent, editable liquid-text experiment inspired by the visual reference. This is **not** the original Maurice Moynihan source and is not pixel-identical.

Open `index.html` with VS Code Live Server. Edit the `settings` object (text, radius, push, stiffness, damping, fontScale, grid). `window.liquidSettings` is also exposed for inspection.

The exact original `liquid.js` was found in the supplied ZIP but is intentionally not republished to this public repository; it is included in the separate downloadable source-study archive.
